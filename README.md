# SIGNAL HAUL

Unity 6.6용 1인칭 물리 등반/회수 게임 프로토타입입니다.

최근 Steam에서 인기를 끈 협동 등반 게임의 **높이·스태미나 기반 긴장감**과 물리 기반 회수 게임의 **귀중품을 직접 들고 운반하는 위험/코미디**에서 착안하되, 세계관·레벨·규칙·코드는 독자적으로 구성했습니다.

## 게임 루프

1. 폭풍 속 폐기된 중계탑을 오른다.
2. 상층부에 흩어진 Signal Core 3개를 찾는다.
3. `E`로 코어를 물리적으로 붙잡고 낙하/드론을 피해 지상 Extraction Pad까지 운반한다.
4. 제한 시간 안에 3개를 모두 회수하면 승리한다.

추락과 드론 충돌은 체력을 깎고 들고 있던 코어를 떨어뜨립니다. 달리기와 벽 등반은 스태미나를 소비합니다.

## 조작

- `WASD`: 이동
- `Mouse`: 시점
- `Left Shift`: 달리기
- `Space`: 점프 / 공중에서 벽을 바라보며 길게 누르면 등반
- `E`: 물체 잡기 / 놓기
- `Q`: 잡은 물체 던지기
- `R`: 게임 종료 후 재시작
- `Esc`: 마우스 커서 해제/잠금

## 실행

1. Unity Hub에서 **Unity 6000.6.0f1 (Unity 6.6)** 로 이 폴더를 엽니다.
2. 첫 스크립트 컴파일 후 `Assets/Scenes/Main.unity`가 자동 생성되고 Build Settings에 등록됩니다.
3. `Main` 씬을 열고 Play를 누릅니다. 씬이 아직 생성되기 전이어도 아무 빈 씬에서 Play하면 런타임 부트스트랩이 동작합니다.

외부 에셋/패키지 없이 Unity 기본 Primitive와 런타임 머티리얼로 월드가 생성되므로 저장소를 클론한 직후 바로 프로토타입을 확인할 수 있습니다.

## 프로토타입 범위

- 1인칭 CharacterController
- 점프/달리기/벽 등반 + 스태미나
- 물리 기반 Rigidbody 잡기/놓기/던지기
- 절차형 수직 스캐폴드 레벨
- Signal Core 3개 회수 및 Extraction Pad
- 순찰/추격 드론, 충돌 피해/넉백
- 폭풍 제한 시간, 체력/스태미나/목표 HUD
- 승리/패배/재시작 루프
